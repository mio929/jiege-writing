# 交叉引用

Word 的「插入 → 交叉引用」本质是插入一个 `REF` 域，域的开关决定取什么内容。理解这一点，手工插和程序插就是同一件事。

## 三种引用类型

| 要引的东西 | 引用类型 | 引用内容 | 前提 |
|---|---|---|---|
| 参考文献编号 | 编号项 | 段落编号 | 文献表必须是 Word 自动编号列表 |
| 章节号 / 节标题 | 标题 | 编号、标题文字 | 标题套用了内置标题样式，或有自动编号 |
| 图、表 | 图 / 表 | 只有标签和编号 | 图表先加过「题注」 |

论文里实际用到的基本就这三类。脚注、公式用得很少，机制相同，不赘述。

## 域开关

```
 REF _Ref123456 \n \h
```

- `\n` —— 取段落编号（不含后面的句点）。文献引用必须带这个。
- `\r` —— 取完整段落编号（含多级，如 2.3.1）。
- `\w` —— 取完整标题文字（含编号）。
- 什么都不加 —— 取书签包裹的那段文字。
- `\h` —— 变成可跳转的超链接。不加就只能看不能点。

域结果分三段：`begin` → `instrText`（代码）→ `separate` → 缓存值（显示的文字）→ `end`。缓存值写对了，打开就正常显示，不必先按 F9。

## 本技能的自动实现

`scripts/build_docx.py` 不走 Word UI，直接生成上述结构，效果与手工插入完全一致。

### 参考文献

稿件里写 `{{zhu2017}}`，脚本做四件事：

1. 按首次出现顺序给文献编号 1…n；
2. 文献表做成 Word 自动编号列表，格式 `[%1]`，编号后缀用**制表符**（`w:suff="tab"`），段落设 21 pt 制表位 + 悬挂缩进，`[1]` 与 `[27]` 后文字对齐同一位置；
3. 每条文献段落包一个书签 `_RefW001`、`_RefW002`…；
4. 正文插入 ` REF _RefW001 \n \h `，缓存值写 `[1]`，整段 run 设上标、字号与正文一致。

方括号由编号格式 `[%1]` 带出，**正文不要再加括号 run**，否则显示成 `[[1]]`。

### 章节

标题里的编号（`2.3`）单独成 run，用书签 `_Sec2_3` 包住；正文写 `{{@2.3}}`，生成 ` REF _Sec2_3 \h `，域结果即书签文本「2.3」。

中文正文里**少用**这种指路语。句首写「沿用第 2 节的扩增子路线」打断阅读；要指路就写「见 2.3 节」放在句末或括注里，全文控制在四五处以内，多数情况把话说完整即可（「按梅花形五点混样」）。

## 图表题注（脚本未内置，手工三步）

1. 选中图片或表格 → 引用 → 插入题注，标签选「表」或「图」，得到「表 1 xxx」。编号由 `SEQ` 域维护。
2. 正文要引用的地方 → 插入 → 交叉引用 → 类型选「表」→ 内容选「只有标签和编号」→ 选中对应题注。
3. 增删图表后 Ctrl+A → F9，编号自动重排，正文引用跟着变。

生成的域形如 ` REF _Ref223344 \h `，与文献引用的区别只在于少了 `\n`——因为题注里有现成的编号文字，不需要取段落编号。

## 上标

选中**完整编号**（含方括号）→ Ctrl+Shift+= 或「开始 → 上标」。

字号必须显式设为与正文一致（小四 12 pt）。Word 的上标会自动缩小显示，如果这一处设 12 pt、那一处设 10.5 pt，打印出来大小不一，一眼能看出来。

## 更新与排错

`Ctrl+A` → `F9` 只重算域，不动正文；`Ctrl+Shift+F9` 会把域转成死文字，之后就失去联动，交稿前不要按。

| 现象 | 成因 | 改法 |
|---|---|---|
| 显示「错误！未找到引用源」 | 书签被删、改名，或域里名字写错 | 重新插入；批量生成时书签名与编号绑定（`_RefW%03d`）最稳 |
| 显示 `[[1]]` | 编号格式已带方括号，正文又加了一层 | 去掉正文里的括号 run |
| 点击不跳转 | 域里缺 `\h` | 补上开关；Word 默认需 Ctrl+单击 |
| 编号全是 1 | 文献没做成自动编号列表，而是手打数字 | 改用列表编号，或重新生成 |
| 更新后编号与文献表不一致 | 正文引用顺序变了但文献表没重排 | 顺序编码制要求按首次出现排号，重排后须整体重算 |
| 上标忽大忽小 | 各处的上标 run 字号不一致 | 统一设为正文磅值 |
