# 参考文献著录与核验

## 版本与适配

2015 版与 2025 版目前并存，按学校给的文件走，不要自作主张。

**GB/T 7714-2025**（2025-12-02 发布，2026-07-01 实施）与 2015 版的实际差异只有三条：

1. **西文责任者姓氏只首字母大写**。2015 版要求全大写（`FIERER N`），2025 版改为 `Fierer N`。
2. **DOI 成为电子资源的必备著录项**。
3. **期刊无卷号时写「年份(期号)」**，年份与括号之间不加逗号。

多数学校的模板仍按 2015 版执行，且示例条目不列 DOI。`format_ref()` 的默认输出取两版通用的部分，**不列 DOI**；确需 DOI 时在 refs 里直接给排好的字符串。

## 拼装顺序

标点按语种切换，这是最容易出错的地方：中文条目全角，西文条目半角。

中文期刊条目：

```
责任者，责任者．题名[J]．刊名，年，卷（期）：页码．
```

西文期刊条目：

```
Author A, Author B. Title[J]. Journal, Year, Vol(Issue): pages.
```

细则：

- **中文条目用全角标点**（`，` `．` `：` `（` `）`），**西文条目用半角标点**（`, ` `. ` `: ` `( ` `)`）。中英混排时按题名语种判定整条。
- 责任者之间用全角逗号或「, 」；超过 3 人取前 3 位，中文加「，等」，西文加「, et al」。
- 3 人以内全部列出，不加「等」。
- 西文姓名「姓 名首字母」，名缩写不加点、字母间空一格：`Wood S A`。
- 复姓与前置词按原样：`van der Heijden M G A`、`Delgado-Baquerizo M`。
- 无卷号时写 `年（期）` 或 `Year(Issue)`，年份与括号之间不加逗号：`2026（1）：33`。
- 页码用半字线：`554-565`；原文有转页时写 `554-565+542`。
- 以文章编号代页码的期刊：`2018, 6(1): 110`、`2017, 8: 2224`。
- 每条以句点收尾（中文用 `．`，西文用 `.`）。

## 其他文献类型

| 类型 | 格式 | 示例 |
|---|---|---|
| 图书 `[M]` | 责任者．书名[M]．出版地：出版者，年． | 姚伯英，侯忠良．构筑物抗震[M]．北京：测绘出版社，1990． |
| 学位论文 `[D]` | 责任者．题名[D]．出版地：培养单位，年． | 金宏．导航系统的精度及容错性能的研究[D]．北京：北京航空航天大学自动控制系，1998． |
| 报告 `[R]` | 责任者．题名[R]．出版地：机构，年． | 冯西桥．核反应堆压力管道的LBB分析[R]．北京：清华大学核能技术设计研究院，1997． |
| 会议 `[C]` | 同期刊结构，类型码用 C | — |

传入方式（refs 用字典，`type` 缺省为 `J`）：

```json
"yao1990": {"type": "M", "authors": ["姚伯英", "侯忠良"], "title": "构筑物抗震",
            "place": "北京", "publisher": "测绘出版社", "year": 1990}
```

期刊条目也可以继续用 8 元组 `[作者, 题名, 刊名, 年, 卷, 期, 页码, DOI]`，
DOI 字段保留但不输出。责任者给列表时会自动截断并补「等」；给字符串则原样使用。

## 多项引用

正文同时引多篇文献，顺序编码制下按编号压缩：

| 情形 | 写法 | 说明 |
|---|---|---|
| 单篇 | `[1]` | 可跳转的域 |
| 两篇连续 | `[1,2]` | 2 个不压缩，仍用逗号 |
| 三篇以上连续 | `[1-3]` | 半角短横线，不用波浪线或长破折号 |
| 不连续 | `[1,3-5,8]` | 逗号分隔各区间 |

spec 里写 `{{文献键|文献键|文献键}}`，`build_docx.py` 按首次引用顺序编号后自动压缩，乱序输入会先排序。`check_docx.py` 的文献覆盖校验会扫正文里的 `[n-m]` 模式，合并引用不会漏算。

**多引用是纯文本，不能 Ctrl+单击跳转。** Word 的 `REF` 域只能返回单个编号，表达不了 `[1-3]` 这种范围。每次构建都会重算编号，所以写死的文本始终和文献表一致；只有手工改过 docx 才需要重新生成。

### 要可跳转的手工方案

如果确实需要点击跳转，得改域代码。原理是用数字图片开关 `\#` 覆盖域的显示格式，再把中间项隐藏：

1. 首项域代码改成 `REF _RefW001 \h \#"[0"`，显示为 `[1`（左括号由开关补上）
2. 末项域代码改成 `REF _RefW003 \h \#"0]"`，显示为 `3]`
3. 中间项整段隐藏（右键 → 字体 → 隐藏），再手打一个短横线
4. 更新域

代价是文献增删后要手工重排。课程论文一般不必折腾，写死文本更省事。

## 核验流程

**不要相信记忆里的卷期页。** 每条都查。

1. **有 DOI 的走 Crossref**：`GET https://api.crossref.org/works/{DOI}`，返回的 `volume`/`issue`/`page`/`article-number`/`issued` 是出版方回传的权威值。
2. **没有 DOI 的走期刊官网**：中文期刊多在自家站点给出「年, 卷(期): 页码」，例如 `bulletin.cas.cn`、`pedologica.issas.ac.cn`、`ecologica.cn`。
3. **按题名检索只用于找 DOI**，不能用来确认元数据。`query.bibliographic` 会错配到同名综述、预印本甚至完全不相干的论文。
4. **年份取值规则**：Crossref 的 `issued` 常常是 online-first 日期。Nature Reviews、Global Change Biology 这类先上线后编期的刊物，应取**期卷所属年份**（如 vol 4(1) 是 2023 年 1 月，即便上线于 2022 年 11 月）。
5. **作者名以出版方元数据为准**。Google Scholar 会把复姓拆错（`Bueno de Mesquita` 被拆成 `de Mesquita`），不能照抄。

## 核验渠道的可用性

| 渠道 | 状态 | 说明 |
|---|---|---|
| Crossref API | 可用 | 无需登录；连续请求会 429，需退避重试 |
| 期刊官网 | 可用 | 中文文献首选 |
| Google Scholar | 通常不可达 | 国内网络直连失败；无 API |
| 知网检索页 | 页面能开，抓不到条目 | 结果列表由 JS 渲染，且需机构登录 |

拿不到知网时，如实告知用户「知网需要校园网和登录，我这边进不去」，并说明改用了哪些替代渠道，请用户用校内账号做最后一次核对。不要假装查过。

## 常见错误清单

- 卷期页凭记忆填写，与原文不符
- 姓氏大小写与所订版本不符（2015 版全大写，2025 版只首字母大写）
- 3 人以上却全部列出，或 3 人以内也加「等」
- 刊名大小写被工具改乱（Google Scholar 的 GB/T 模板会把刊名压成句首大写，那是它的缺陷，按原刊著录）
- 页码范围用长横线 `–` 而非半字线 `-`
- **标点混用**：中文条目误用半角逗号或半角句点，西文条目误用全角标点
- **DOI 与模板不符**：学校示例不列 DOI 却列了，或要求列却漏了
- 文献表里有未被正文引用的条目，或正文引用了表里没有的编号
- 编造文献。这是最严重的问题——宁可少一条，不可凭空生成；核验不过就删掉
