# 清单

两份，开工前用一份，交稿前用一份。逐项打勾，别凭记忆。

## 一、开工前

### 要求拆解

- [ ] 拿到原始要求文件（PDF、截图、聊天记录），不是转述
- [ ] 主题范围写下来，一句话能说清
- [ ] 必备组成部分列全（摘要、引言、正文、结论、参考文献…）
- [ ] 关键词个数（常见 3–5 个）
- [ ] 正文字数下限与上限
- [ ] 参考文献总数下限、外文文献下限
- [ ] 字体、字号、行距、页边距
- [ ] 图表的数量与形式要求
- [ ] 署名格式（姓名、学号、班级、指导教师）
- [ ] 提交格式（docx、pdf、纸质）

### 口头约束

作业文件里通常没有，必须问：

- [ ] 篇幅上限（只给下限时问一句）
- [ ] 要不要图表
- [ ] 有没有忌讳的表述（如正文不许出现「第几节」）
- [ ] 是否需要匿名（不署名）

### 定题

- [ ] 选题落在主题范围内
- [ ] 能找到 10 条以上可核验文献
- [ ] 有明确的问题意识，不是资料堆砌

## 二、文献

写作开始前必须完成，顺序不能反。

- [ ] 每条文献都有 DOI 或期刊官网文章页
- [ ] DOI 逐条回查过（`api.crossref.org/works/{DOI}`），不是按题名猜的
- [ ] 卷、期、页与出版方元数据一致
- [ ] 作者数与著录规则匹配（>3 人截断并补「等」/「et al」）
- [ ] 没有编造的条目，核验不过的已删除

## 三、交稿前

### 脚本

- [ ] `python scripts/check_docx.py 论文.docx --strict` 退出码为 0
- [ ] 无残留 `{{}}` 标记
- [ ] 无 `__TABLE_n__` 占位段

### 目视

脚本查不出来的，只能看：

- [ ] 首页标题、作者、摘要、关键词的位置与字号
- [ ] 每页末尾是否有标题落单、正文孤行
- [ ] 表格是否跨页断裂，表题与表格是否同页
- [ ] 表格内文字的字号、行距、对齐（脚本对表格是盲区）
- [ ] 参考文献编号 `[1]`–`[n]` 连续，无跳号
- [ ] 中英文之间是否有空格，括号是否半全角混用
- [ ] 文档属性里没有「python-docx」字样

### 对照要求

- [ ] 字数（按 Word 字数统计，含表格内文字）
- [ ] 文献条数
- [ ] 关键词个数
- [ ] 结构完整，不缺组成部分
- [ ] 格式逐项对上学校模板

### 参考文献

- [ ] 版本对（2015 或 2025）
- [ ] 标点体系对（中文条目全角、西文半角，或按学校要求全半角）
- [ ] DOI 列或不列，与学校示例一致
- [ ] 每一条都在正文里被引用
- [ ] 正文每个引用都能在文献表里找到

## 四、字数口径

「正文 5000 字」在不同口径下能差三四百字，交稿前统一一次：

| 口径 | 含什么 | 典型差异 |
|---|---|---|
| 纯正文汉字 | 只算正文段落 | 基准 |
| 加标题关键词 | 各级标题、关键词、表题 | +100–150 |
| 加表格 | 表格内全部文字 | +150–250 |
| Word 字数统计 | 汉字 + 英文词 + 数字串，含表格 | 最接近学校检查 |

`check_docx.py` 报的是「纯正文 + 标题 + 关键词 + 表题」，不含表格文字。与 Word 的差值正好是表格内容，交付时把两个数都报给用户。
